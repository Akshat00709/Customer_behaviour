📊 Customer Behavior Analysis | Excel, SQL & Power BI

# 📌 Project Overview

This project analyzes customer purchasing behavior to understand product preferences, purchase frequency, subscription patterns, shipping preferences, and delivery performance.

Using Microsoft Excel, MySQL Workbench, and Power BI, the project explores customer demographics and purchasing patterns to identify trends and generate actionable business insights.

## 🎯 Project Objectives

- Analyze customer purchasing behavior and product preferences.
- Understand purchase frequency and shopping patterns.
- Examine customer subscription behavior.
- Analyze shipping preferences and delivery performance.
- Explore purchasing trends across different age groups.
- Develop an interactive dashboard to visualize customer insights.

## 🛠️ Tools & Technologies

- **Microsoft Excel:** Data cleaning, preparation, and exploratory analysis.
- **MySQL Workbench:** SQL queries, filtering, aggregation, and data analysis.
- **Power BI:** Interactive dashboards, KPIs, and data visualization.

## 📂 Project Workflow

1. **Data Preparation:** Cleaned and prepared the customer dataset using Excel.
2. **SQL Analysis:** Used MySQL Workbench to query customer data and analyze purchasing patterns.
3. **Data Visualization:** Built an interactive Power BI dashboard to present customer behavior trends.
4. **Business Insights:** Examined customer segments, subscriptions, shipping preferences, and delivery metrics.

## 🔍 Business Questions

- Which product categories do customers purchase?
- How frequently do customers make purchases?
- What patterns can be observed in customer subscriptions?
- Which shipping options are preferred by customers?
- How does purchasing behavior vary across age groups?
- How quickly are orders delivered?
- What differences exist between subscribed and non-subscribed customers?

## 📈 Key Performance Indicators (KPIs)

The dashboard can include the following metrics, depending on the fields available in your dataset:

- Total Customers
- Total Purchases or Orders
- Average Purchase Frequency
- Subscription Rate
- Average Purchase Amount
- Average Delivery Time
